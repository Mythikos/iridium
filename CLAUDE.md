# CLAUDE.md

Guidance for Claude Code (claude.ai/code) when working with code in this repository.

Everything is in one shared file — [`docs/repository-guide.md`](docs/repository-guide.md) — which `AGENTS.md` points at as well, so every agent working here reads the same rules. Read it in full before making any change. It is binding, and the only thing that overrides it is the development plan in `docs/plan/`, which is the specification.

It covers the project overview, the architecture, the pinned technology stack, the repository layout and its boundary tags, the maintainer's coding standards, the key design principles, documentation lookup, the development commands, the database, the API surface, configuration, security, how to work with the plan, and the milestone status.

Add nothing to this file: guidance belongs in the shared guide, where both agents will see it.
